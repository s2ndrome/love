GitHub 토큰은 어떻게 만들어요? (처음 한 번만)
  1. GitHub 로그인 후 github.com/settings/personal-access-tokens/new 접속
  2. Repository access → Only select repositories 선택 → s2ndrome/love 선택
  3. Permissions → Contents → Read and write로 설정
  4. Generate token → 생성된 토큰(github_pat_...) 복사
  5. 아래 칸에 붙여넣기 — 이 브라우저에만 저장되고, 딱 이 저장소에만 쓸 수 있어요 (갤러리 업로드 도구랑 같은 토큰 써도 돼요)
