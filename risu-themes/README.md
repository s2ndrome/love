# RisuAI 채팅 테마 6종

diary 로그 스타일(3인칭 소설체, 굵은 하늘색 대사, blockquote 삽입 문서, hr 장면 구분)에 맞춘 채팅 본문 테마.
`preview.html`을 브라우저로 열면 6개를 바꿔 보면서 CSS를 복사할 수 있다.

| 파일 | 이름 | 느낌 |
|---|---|---|
| 01-novel.css | 문고본 | 소설책 지면, 고운바탕, 하늘색 대사, 드롭캡 |
| 02-editorial.css | 에디토리얼 | 블로그 사이트와 같은 흰 지면 + #2d46ff |
| 03-sclass.css | S급 기록 | 검정 + 주황 HUD, SYSTEM 창 |
| 04-messenger.css | 메신저 | 대사 말풍선, 지문은 작게 |
| 05-bedtime.css | 새벽 네 시 | 남색 밤 + 스탠드 주황빛 |
| 06-rushes.css | 러시스 | 레터박스, 시나리오 타자체, 영화 자막 |

## 적용

1. 설정 → 디스플레이 → 커스텀 CSS에 붙여넣기. 없으면 캐릭터 배경 임베딩에 `<style>…</style>`로 감싸서.
2. 대사가 안 칠해지면 정규식 스크립트(출력문 수정) 추가
   - IN: `["“]([^"”\n]+)["”]`
   - OUT: `<span class="dlg">"$1"</span>`
3. 테마는 메시지 본문 `.chattext`에 걸려 있다. 버전에 따라 다르면 F12로 확인해서 바꾼다.

대사 선택자는 `.dlg`, `.x-risu-dlg`, `span[data-q]`를 모두 잡는다.
