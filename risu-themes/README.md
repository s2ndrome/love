# RisuAI 채팅 테마 6종

diary 로그 스타일(3인칭 소설체, 굵은 하늘색 대사, blockquote 삽입 문서, hr 장면 구분)에 맞춘 채팅 테마.
메시지를 카드로 나누지 않고 채팅 화면 전체가 한 장의 지면으로 이어진다.
테마마다 `.html`(배경 지면과 장식)과 `.css`(화면 색 + 본문 글씨)가 한 쌍.
`preview.html`을 브라우저로 열면 6개를 바꿔 보면서 복사할 수 있다.

| 테마 | 이름 | 느낌 |
|---|---|---|
| 01-novel | 문고본 | 소설책 한 쪽, 고운바탕, 하늘색 대사 |
| 02-editorial | 에디토리얼 | 블로그와 같은 흰 지면 + #2d46ff |
| 03-sclass | S급 기록 | 검정 + 주황 단말, 네 귀퉁이 브래킷 |
| 04-messenger | 메신저 | 톡방 상단바, 대사 말풍선 |
| 05-bedtime | 새벽 네 시 | 남색 밤 + 스탠드 주황빛, 별, 달 |
| 06-rushes | 러시스 | 레터박스, 필름 구멍, 영화 자막 |

## 적용

1. 간단하게: HTML 뒤에 CSS를 `<style>…</style>`로 붙여서 캐릭터 설정의 배경 임베딩에 넣는다.
2. 따로: HTML은 배경 임베딩, CSS는 설정 → 디스플레이 → 커스텀 CSS.
3. CSS의 `:root` 변수(`--risu-theme-*`)가 리스 화면 전체 배경과 글씨색을 바꾼다.
4. 대사가 안 칠해지면 정규식 스크립트(출력문 수정) 추가
   - IN: `["“]([^"”\n]+)["”]`
   - OUT: `<span class="dlg">"$1"</span>`
5. 본문은 `.chattext`에 걸려 있다. 버전에 따라 다르면 F12로 확인해서 바꾼다.

배경 클래스는 `.lv-*`와 리스가 붙이는 `.x-risu-lv-*`를 모두 잡는다.
대사 선택자는 `.dlg`, `.x-risu-dlg`, `span[data-q]`를 모두 잡는다.
