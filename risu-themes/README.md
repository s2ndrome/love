# RisuAI 채팅 테마 6종

리스 **커스텀 채팅 HTML + 커스텀 CSS** 방식.
프로필 사진(`<risuicon>`) 없이, 메시지가 칸으로 나뉘지 않고 채팅 화면 전체가 한 장으로 이어진다.
`preview.html`로 미리 볼 수 있다.

- HTML 틀: `0N-*.html` (6개 모두 같은 틀. 한 번 넣고 CSS만 바꿔 끼우면 됨)
- CSS: `0N-*.css`

| 테마 | 이름 | 느낌 |
|---|---|---|
| 01-novel | 문고본 | 미색 종이, 고운바탕, 하늘색 대사 |
| 02-editorial | 에디토리얼 | 흰 지면, 파란 포인트, 모노 이름 |
| 03-sclass | 기록 단말 | 검정 + 주황, 네 귀퉁이 브래킷 |
| 04-messenger | 메신저 | 캐릭터 회색 말풍선(왼쪽), 유저 파란 말풍선(오른쪽) |
| 05-bedtime | 새벽 네 시 | 남색 밤 + 스탠드 주황빛, 별 |
| 06-rushes | 러시스 | 레터박스, 필름 구멍, 영화 자막 |

## 적용

1. HTML → 커스텀 채팅 HTML 칸
2. CSS → 커스텀 CSS 칸

- 이름은 `{{role}}`에 따라 `{{char}}` / `{{user}}`로 채워진다.
- 대사는 리스가 자동으로 붙이는 `mark[risu-mark]`로 꾸민다. 정규식 필요 없음.
- 버튼(`<risubuttons>`)은 이름 옆에 작고 흐리게 두었다.
